# [2.2] grafo de deps

O `.t.js` re-roda quando o alvo muda — mas também quando qualquer coisa que o alvo importa muda.

## Objetivo

O `.t.js` re-roda quando o alvo muda — mas também quando qualquer coisa que o alvo importa
muda. `deps()` segue os três formatos de import (o de efeito colateral domina este repo:
é como um plugin se registra) recursivamente dentro da raiz, com memoização por chave
`entryPath + extraRoots`.

## Estado atual — 🟡 testada

`cache.t.js` §"o grafo de dependências" (7 testes): efeito colateral sem `from`, `from`
dinâmico + re-export, vários saltos sem repetir, ciclo, pacote externo ignorado, import
irresolúvel, `extraRoots`. Verde 2026-09-03.

## Accomplishments

- `IMPORT_RE` cobre a terceira forma (`import './x'`) — perdê-la deixava `scl/button.t.js`
  com ZERO deps.
- `extraRoots` é o que liga o modelo do `.eval.js`: o `.md` não importa nada, o grafo real
  é o `files:` do frontmatter, passado como `extraDeps` por `utest.js#runPhase`.

## Debts

- `resolveImport` só cobre `.js`/`.ts`/`/index.(js|ts)` e caminhos relativos — um alias de
  bundler ou um import sem extensão exótico escaparia.
- Sem `.eval.js` (`2.2.eval.js`).
