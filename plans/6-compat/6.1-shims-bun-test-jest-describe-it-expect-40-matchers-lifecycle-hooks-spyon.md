# [6.1] shims bun:test / jest

Uma suíte legada não deve precisar ser reescrita para rodar aqui.

## Objetivo

Uma suíte legada não deve precisar ser reescrita para rodar aqui. `shims.js` mapeia o
vocabulário de `bun:test`/`jest` para a árvore de `test()` + `check()` do utest.

## Estado atual — 🟠 implementando

Roda (a suíte do soml tem `.t.js` em estilo misto). **Sem `shims.t.js`** — ~40 matchers,
`.not`/`.resolves`/`.rejects`, `partialMatch` recursivo, e nenhum prende o comportamento.
→ 🟠, e é uma das dívidas mais gordas do repo.

## Accomplishments

- Cobertura de matcher ampla o suficiente para o corpus real do soml não tropeçar.
- `test.scope` resolve o problema clássico: `test()` dentro de uma arrow-fn de `describe`
  cai no describe certo, não no root.

## Debts

- **Sem teste próprio.** Um matcher com bug (ex.: `toMatchObject` recursivo, `rejects`
  não-esperando) só apareceria como falha misteriosa num `.t.js` de consumidor.
- `expect().toThrow(msg)` faz mais que `checkException` de [[1.2]] — assimetria não
  resolvida.
- Sem `.eval.js` (`6.1.eval.js`).
