# [4.6] v2 continuo: rio de passados, bloco cheio so nos falhos

## Objetivo

`-v:2` mostrava uma barra de titulo (dotfill + tempo) por ARQUIVO, verde ou
vermelho -- ruido numa fase com muitos arquivos. Passa a seguir a mesma logica
de "so quem pede atencao ganha espaco" que `compactFails` ja aplica em `-v:1`:
passados formam um rio continuo, falhos ganham o relatorio cheio.

## Eval

### 4.6#1 · fixture com 2 verdes + 1 vermelho

> `bun utest.js utest/viewer.t.js` cobre a unidade; este passo mostra o
> resultado fim-a-fim contra um cenario real de 3 arquivos.

```console
$ mkdir -p /tmp/utest-4.6-fixture && printf "test('a', ({ check }) => { check(1, 1) })\n" > /tmp/utest-4.6-fixture/a.t.js && printf "test('b', ({ check }) => { check(2, 2) })\n" > /tmp/utest-4.6-fixture/b.t.js && printf "test('c', ({ check }) => { check(2 + 2, 5) })\n" > /tmp/utest-4.6-fixture/c.t.js && bun utest.js /tmp/utest-4.6-fixture -v:2 --force 2>&1 | sed 's/\x1b\[[0-9;]*m//g'
```
