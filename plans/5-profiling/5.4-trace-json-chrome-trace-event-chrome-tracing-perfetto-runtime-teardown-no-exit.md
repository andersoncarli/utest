## Objetivo

A árvore textual é até a última linha do script; o `time` de parede ainda soma ~Ns de
teardown do bun (finalizar um module-graph gigante, handles unref'd). `finalize` captura
isso de `process.on('exit')` e o `trace.json` fica com o total batendo com o `time`.

## Estado atual — 🟡 testada

`trace.t.js`: "chromeTrace() emite Chrome Trace Event — ts/dur em µs, tid por
profundidade", "writeChromeTrace grava um JSON válido". Verde 2026-09-03. O
`(runtime teardown)` no exit é observado só na prática (roda no `process.on('exit')`).

## Accomplishments

- Um formato só para dois consumidores (chrome://tracing e Perfetto) — nenhuma segunda
  contabilidade.

## Debts

- `finalize` registra um `process.on('exit')` — se `utest.js` for importado como módulo
  (não como CLI), esse handler acumula. Hoje só o CLI chama.
- Sem `.eval.js` (`5.4.eval.js`).
