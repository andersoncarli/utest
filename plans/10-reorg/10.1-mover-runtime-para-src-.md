# [10.1] mover runtime para src/

## Objetivo

Sair de um runtime solto na raiz do repo (`utest.js`, `src/cache.js`, `src/viewer.js`,
`src/scanner.js`, etc.) para `src/` (ja existe, vazio), sem quebrar a dependencia externa em
`~/utils` nem a cobertura de `sprint files`.

## Passos

1. `utest/utils` -> symlink para `~/utils` (feito). Import interno passa a ser relativo a
   esse link, nao a `../utils` fora do repo — distancia fixa mesmo se `src/` ganhar
   subpastas depois.
2. Mover cada arquivo `.js`/`.t.js` do runtime para `src/` via `sprint rename <old> <new>
   --apply`, preservando o mapa `files:` do frontmatter de cada feature.
3. Reescrever imports que hoje sao `../utils/src/*` / `../utils/globals.d.js` para
   `../utils/...` relativo a nova posicao em `src/` (agora resolvendo pro symlink local).
4. Atualizar `package.json` (`bin`, `main`) para os novos caminhos.
5. `utest .` e `sprint files` para confirmar que nada regrediu.
